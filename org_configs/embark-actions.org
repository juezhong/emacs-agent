* 完整默认动作参考

以下表覆盖核对版本主包、Org 集成和 Consult 集成中定义的所有动作 keymap 及补充绑定。
只记录默认键位，不复制或改写它们。表中的动作键都在 C-. 之后输入；
子菜单继续输入后续键，例如文件 v r 是 VC 重命名，选区 > b 是 Base64 编码。
相同按键在不同目标可含义不同；先看当前目标。局部表覆盖父表同名按键，未覆盖项沿父表继承，
因此没有在每一张表重复写通用动作。数字和负号用于给动作提供前缀参数。
RET 是动态默认动作，minibuffer 中通常使用原候选命令的确认动作，可能覆盖表内静态 RET；
Org 标题引用默认跳到标题，标题正文默认切换 TODO，不可把所有 RET 解释为同一种操作。
C-h 动作帮助和用于目标循环的 C-. 由运行时加入；C-g 取消，不是待执行的目标动作。
“交互命令”列用于查帮助；子菜单 keymap 及仅在菜单内部有效的控制动作，不适合单独 M-x 调用。

** 动态分派、Consult 搜索与继承补充

上表共 48 张默认表、434 条直接绑定（含 Org / Consult 后加到原表的 4 条绑定），
继承项按父表补齐；以下补充运行时组合与非 defvar-keymap 形式的子菜单。

- 通用表 C：embark-consult-search-map，组合上面的 Consult 同步和异步搜索表；例如 C-. C r 启动 consult-ripgrep。
- B 是命令切换而非目标类型切换；只在 minibuffer 中工作。当前命令所属的 become 表才会出现，
  可在该状态用 M-x 选择新命令；C-h 帮助按当前可用表补全。
- B 的匹配切换表中 C 进入 Consult 同步搜索表；异步搜索表也加入 become 家族。
  同一搜索家族可保留输入切换，例如 consult-ripgrep 中 C-. B g 转 consult-grep。
- Org URL / 邮件 / 文件 / 表达式链接先使用 embark-org-link-map，再组合相应 url / email / file / expression 表，
  仍可操作底层目标；链接 w 进入复制子菜单，w w 复制内部目标，w f 复制完整 Org 链接。
- org-timestamp、org-footnote-definition、org-footnote-reference 等没有专门动作表的已识别对象，
  回退到通用表；没有为它们禁用通用复制、插入、选择等动作。
- consult-location、consult-grep、consult-xref、consult-isearch-history、consult-man、consult-info
  由桥接处理转换、默认跳转或打开，以及适用的专用导出；没有另造一张只有少数动作的替代表。

** Smerge 冲突目标及比较子菜单

Embark 对 smerge 目标组合内置 smerge-basic-map 与通用表，以 Smerge 同键优先。
以下核对本机 Emacs 31.1 的 smerge-mode.el；其他 Emacs 版本以安装版本为准。

| 快捷键 | 交互命令（M-x 名称） | 作用 |

| b | smerge-keep-base | 保留共同祖先版本 |
