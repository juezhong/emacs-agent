* 确定方案

| 项目 | 取值 | 说明 |
|------+------+------|
| 英文字体 / 字号 | JetBrainsMono NFM / 10 | cnfonts-personal-fontnames 第一组；cnfonts-default-fontsize |
| 中文字体 / 字号 | LXGW WenKai Mono GB / 12 | 第二组；12 来自 cnfonts 内置字号表中英文 10 对应的那一行 |
| 存档名 | main | cnfonts-profiles；决定 .cache/cnfonts/v4/main.el 的文件名 |
| 保存位置 | .cache/cnfonts/ | cnfonts-directory，已被 Git 忽略；启动时自动创建 |

* cnfonts 是怎么决定字体和字号的

启动应用字体时，cnfonts 按下面的顺序取值（源码 =cnfonts-set-font=、=cnfonts--read-profile=）：

1. 读取 =cnfonts.conf=，得到当前存档记录的英文字号；没有记录才用 =cnfonts-default-fontsize=。
2. 读取存档文件 =v4/main.el=，得到字体名列表和字号表；再把 =cnfonts-personal-fontnames=
   和内置候选依次合并在后面（已有的名字不重复）。
3. 每组字体取列表里“系统已安装的第一款”；用英文字号在字号表里找到对应行，得到其余各组的字号。
4. 应用字体，并把当前字号和合并后的存档重新写回 =cnfonts.conf= 和 =main.el=。

所以 Org 里的两个选项只在“首次”起作用，之后存档文件是主导。这是 cnfonts 的原生设计。

* 核对记录

下面几条结论用 cnfonts 的批处理（无图形界面，直接调用 =cnfonts-set-font= 并读写临时目录）实验核对：

| 现象 | 结果 |
|------+------|
| 已有 cnfonts.conf 记录 10，把 Org 默认改成 12 | 仍是 10；删除 cnfonts.conf 后变成 12 |
| 已有 main.el，把 Org 字体列表改成 Cascadia 在前 | 旧的 JetBrainsMono NFM 仍排第一；删除 main.el 后 Cascadia 排第一 |
| 手工把字号表 10 一行的中文改成 11.5 | 重启后保留，并被原样写回 main.el |

实验没有渲染字体，只核对数值和顺序；图形界面的实际效果仍需你启动后确认。

* Dashboard 图标为什么依赖启动时的字体

Dashboard 插入图标时，插件的 =dashboard-replace-displayable= 用 =char-displayable-p= 检查字符。
该函数按“所选 Frame 的默认字体”判断，默认字体还不是 JetBrainsMono NFM 时，
Nerd 图标字形不可显示，图标就被替换成空串，且不会再补回。
cnfonts-mode 原生在 =window-setup-hook= 才应用字体，晚于 Dashboard 的创建（=emacs-startup-hook=，
启动流程中先于 window-setup-hook，见 Emacs 的 startup.el）。
所以配置在启用 cnfonts-mode 后提前调用一次 =(cnfonts-set-font)=。
这个原因来自源码核对，尚未在图形界面中验证。

* 常见问题

- 初始化报错找不到目录：cnfonts 保存当前字号时不创建目录；配置已在加载 cnfonts 后创建 =cnfonts-directory=。
- 改了 Org 的字号或字体没变化：见上面的核对记录；字号删 cnfonts.conf，字体删 main.el。
- 不要用 =M-x cnfonts-regenerate-profile=：它按源码把内置候选写成存档（=cnfonts--save-profile= 的 use-fallback 分支），
  之后你的 cnfonts-personal-fontnames 会排在 Monaco、微软雅黑等内置候选之后，等于放弃你的选择。
  需要重置存档时删除 main.el。
- 旧存档文件（body.el 等）：存档名改后不再读取，可以删除，不影响配置。
- Windows 中英文不对齐：保持 =cnfonts-use-face-font-rescale= 为 nil，调字号表里中文那一列。
- 图标显示方框：这是 nerd-icons 字体问题，与 cnfonts 无关，安装 Symbols Nerd Font Mono。
- 终端 Emacs：字体由终端决定，cnfonts 不生效；cnfonts 的字号命令会提示不支持。
